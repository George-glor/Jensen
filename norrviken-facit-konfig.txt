NORRVIKEN CYKEL - FACIT, FÄRDIG KONFIGURATION
Dator- och kommunikationsteknik 3 / Cisco Packet Tracer
=====================================================================

Så här använder du filen:
1. Bygg topologin och dra kablarna enligt del 2 i labben.
2. Klicka på enheten, välj fliken CLI och svara "no" på frågan om
   initial configuration dialog.
3. Kopiera hela blocket för enheten och klistra in det i CLI.
4. Gör likadant för nästa enhet.
5. Ställ in PC, servrar och access points för hand enligt slutet av filen.

Konfigurationen motsvarar färdigt läge efter del 4-12.
Del 14 (Sollentuna) och del 15 (extra) finns i labbens facit.
Byggd för Cisco 2911 och 2960-24TT.


=====================================================================
R1  (huvudrouter, Järfälla)
=====================================================================
enable
configure terminal
hostname R1
no ip domain-lookup
enable secret class
service password-encryption
banner motd #Endast behorig personal. Obehorig atkomst ar forbjuden.#
ip domain-name norrviken.local
username admin secret Norrviken2026!
!
line console 0
 password cisco
 login
 exit
!
interface g0/0
 description Trunk till SW1
 no shutdown
 exit
interface g0/0.10
 description PERSONAL
 encapsulation dot1Q 10
 ip address 192.168.10.1 255.255.255.0
 ip nat inside
 exit
interface g0/0.20
 description KASSA
 encapsulation dot1Q 20
 ip address 192.168.20.1 255.255.255.0
 ip nat inside
 exit
interface g0/0.30
 description GAST
 encapsulation dot1Q 30
 ip address 192.168.30.1 255.255.255.0
 ip nat inside
 exit
interface g0/0.99
 description MGMT
 encapsulation dot1Q 99
 ip address 192.168.99.1 255.255.255.0
 ip nat inside
 exit
interface g0/1
 description Till R2 Kallhall
 ip address 10.0.0.1 255.255.255.252
 ip nat inside
 no shutdown
 exit
interface g0/2
 description Till ISP
 ip address 203.0.113.2 255.255.255.252
 ip nat outside
 no shutdown
 exit
!
ip dhcp excluded-address 192.168.10.1 192.168.10.20
ip dhcp excluded-address 192.168.20.1 192.168.20.20
ip dhcp excluded-address 192.168.30.1 192.168.30.20
ip dhcp pool PERSONAL
 network 192.168.10.0 255.255.255.0
 default-router 192.168.10.1
 dns-server 192.168.10.10
 exit
ip dhcp pool KASSA
 network 192.168.20.0 255.255.255.0
 default-router 192.168.20.1
 dns-server 192.168.10.10
 exit
ip dhcp pool GAST
 network 192.168.30.0 255.255.255.0
 default-router 192.168.30.1
 dns-server 192.168.10.10
 exit
!
ip route 192.168.50.0 255.255.255.0 10.0.0.2
ip route 0.0.0.0 0.0.0.0 203.0.113.1
!
access-list 1 permit 192.168.0.0 0.0.255.255
ip nat inside source list 1 interface g0/2 overload
!
ip access-list extended GAST-IN
 permit udp any any eq bootps
 permit udp 192.168.30.0 0.0.0.255 host 192.168.10.10 eq domain
 deny ip 192.168.30.0 0.0.0.255 192.168.0.0 0.0.255.255
 permit ip 192.168.30.0 0.0.0.255 any
 exit
interface g0/0.30
 ip access-group GAST-IN in
 exit
!
crypto key generate rsa general-keys modulus 1024
ip ssh version 2
line vty 0 4
 login local
 transport input ssh
 exit
end
write memory

=====================================================================
ENHETER SOM STÄLLS IN FÖR HAND (Desktop / Config / Services)
=====================================================================

SRV1  (Desktop -> IP Configuration)
  IP 192.168.10.10   Mask 255.255.255.0
  Gateway 192.168.10.1   DNS 192.168.10.10
  Services -> HTTP: på. Ändra index.html till "Norrviken Cykel intranät".
  Services -> DNS: på. Lägg till A-poster:
    intranat.norrviken.local  ->  192.168.10.10
    www.cykeldelar.test       ->  198.51.100.10

WEB-ISP  (Desktop -> IP Configuration)
  IP 198.51.100.10   Mask 255.255.255.0
  Gateway 198.51.100.1
  Services -> HTTP: på. Ändra index.html till något eget.

PC1, PC2, PC3, PC4, GAST, PC5, PC6
  Desktop -> IP Configuration -> DHCP

AP-PERSONAL  (Config -> Port 1), kopplad till SW1 Fa0/3
  SSID Norrviken-Personal   WPA2-PSK   lösenord CykelPersonal26   kanal 1

AP-GAST  (Config -> Port 1), kopplad till SW1 Fa0/12
  SSID Norrviken-Gast   WPA2-PSK   lösenord cyklarcyklar   kanal 6

LAP-PERSONAL
  Stäng av, byt nätverkskort till WPC300N, starta.
  Anslut till Norrviken-Personal. IP via DHCP (192.168.10.x).

MOBIL-GAST  (Smartphone-PT)
  Config -> Wireless0: SSID Norrviken-Gast, WPA2-PSK, cyklarcyklar.
  IP via DHCP (192.168.30.x).
