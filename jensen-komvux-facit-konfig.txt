JENSEN KOMVUX - FACIT, FÄRDIG KONFIGURATION
Dator- och kommunikationsteknik 3 / Cisco Packet Tracer
=====================================================================

Så här använder du filen:
1. Bygg topologin och dra kablarna enligt del 2 i labben.
2. Klicka på enheten, välj fliken CLI och svara "no" på frågan om
   initial configuration dialog.
3. Kopiera hela blocket för enheten och klistra in det i CLI.
4. Gör likadant för nästa enhet.
5. Ställ in server, WLC, PC och IoT för hand enligt slutet av filen.

Blocken ger färdigt läge efter del 4-12.
IPv6 (del 9), nya våningen (del 14) och extra (del 15) ligger i egna
block längre ner, eftersom de kräver omstart eller nya enheter.

Byggd för: 3560-24PS (DSW1, DSW2), 2960-24TT (ASW1, ASW2),
2911 (R-EDGE, ISP), WLC-2504.

DEL 9: IPv6 PÅ DSW1  (kör när allt ovan fungerar)
=====================================================================

enable
configure terminal
sdm prefer dual-ipv4-and-ipv6 default
end
write memory
reload

! Steg 2. Efter omstarten:
enable
configure terminal
ipv6 unicast-routing
interface vlan 10
 ipv6 address 2001:db8:acad:10::1/64
 ipv6 address fe80::1 link-local
 exit
interface vlan 20
 ipv6 address 2001:db8:acad:20::1/64
 ipv6 address fe80::1 link-local
 exit
end

! PC-L1 och PC-E1: IPv6 Configuration -> Automatic.
